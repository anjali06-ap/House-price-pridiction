# House-price-pridiction
A machine learning project that predicts residential property prices based on various features such as area, location, and property attributes.
📌 Project Overview
The objective of this project was to analyze housing data and build a predictive model that estimates the market price of a house. This project demonstrates my skills in data preprocessing, exploratory data analysis (EDA), and machine learning model implementation.
🛠 Tech Stack
Language: Python
Libraries:
pandas & numpy (Data manipulation)
matplotlib & seaborn (Data visualization)
scikit-learn (Model training and evaluation)
Tools: Jupyter Notebook / VS Code
